# 漢字複習小幫手

給女兒學漢字用的手機網頁 App，以「句子」為主的學習方式：每天新增一個學到的漢字或詞彙，AI 立刻圍繞它生成 5 句練習句子，當場念、當場拿星星；之後隨時可以回到紀錄裡，把之前任何一批句子再拿出來複習一次。

## 功能

- **新增漢字／詞彙 + 產生句子（合併在同一頁）**：輸入一個今天學到的漢字或詞彙（例如「學」或「毛毛蟲」），自動查出注音，遇到破音字可以手動選擇正確讀音。如果這個字或詞其實已經學過了，不會重複登錄，而是直接告訴你「已經學過囉」並帶去造句練習。存好（或確認已學過）之後，同一頁下方會出現難度選擇（簡單／中等／困難，難度越高句子越長、念對了星星也越多：2／3／5 顆），可以按「產生 5 句練習句子」讓 AI 生成，也可以按「自己寫句子」完全自己造句、不透過 AI。AI 會用這個字或詞加上已經學過的其他字，生成 5 句都完整包含它、盡量組成真實詞彙／句子的句子（例如目標是「學」，可能生成「我去學校上學」「學生喜歡老師」；目標是「毛毛蟲」就直接把這個詞用進句子裡），而不是把字硬塞進句子裡；後端也會檢查生成結果，過濾掉沒有包含目標或長度不符的句子。**生成之後不會馬上存起來**，而是先進到一個可以編輯的清單：每一句都可以直接改文字、按「✕」刪掉不要的，也可以自己另外寫一句加進去，覺得整批都不滿意還可以按「換一批 AI 句子」重新生成（已經寫好/改好的句子不會被換掉，只換 AI 原本沒動過的那些）；確認好之後按「開始練習這 N 句」才會真正存起來、開始練習。之後只要針對同一個字或詞再生成句子，AI 會參考你之前寫過或修改過的句子的用字風格，盡量生成類似自然的句子，而不是每次都不知道你要的風格重來一次。如果你之前已經幫某個字寫過／改過中等或困難難度的例句（探索過這個字的不同用法），這次改選「簡單」難度再生成時，AI 不會另外亂發明新句子，而是會把你那些例句展示的不同用法，各自濃縮改寫成更短、更簡單的版本，盡量一種用法對應一句簡化過的句子。存起來的句子會標記是「AI」生成的、「你寫的」還是「你修改過」的，可以在「管理句子庫」裡看到。開始練習中，如果覺得某一句可以念更好，句卡下方有「✏️ 這句可以改得更好？點這裡修改」，可以直接在當下修改文字，存好後句卡會立刻顯示新的內容（不用等練習完再去「管理句子庫」找）。開始練習後，念完由旁邊的人（或她自己）按「我念對了」拿星星，念錯按「先跳過」，不做語音辨識判斷（不準確，容易誤判打擊信心）。因為不判斷內容對不對，「我念對了」加了兩層防呆，避免句子都還沒看就亂按拿星星：句子剛出現的幾秒內按鈕會先不能按（依句子長度抓最短秒數），而且要先按「錄音念念看」錄過一次音才能按（不判斷錄音內容，只要求真的有開口念）；如果瀏覽器不支援錄音或麥克風權限被拒絕，會自動只保留最短等待時間這一層，不會讓沒有麥克風的家庭卡住按不下去。她也可以按「錄音念念看」把自己念的錄下來，錄完立刻自己播放聽（只在當下播放，不會上傳或保存）。念對了會有星星動畫 + 音效 + 浮誇語音稱讚，畫面上也有一排星星格子會一顆一顆跳出來、跟著念對的句子數累積，讓還不太懂數字的小朋友也能直接「看到」自己拿了幾顆星星，而不用唸數字。整批句子都念完後的結算畫面也重新設計過：會播放一段歡呼慶祝音效（比單句念對的音效更豐富、結尾有和弦）、跳動的🎉圖示、語音念出「太棒了！這次唸了 N 句，得到 M 顆星星！」，畫面上的星星數字也會從 0 蹭蹭蹭地一格一格跳到最終數字（不是一次跳出結果），讓「賺到星星」有真正的快感。
- **直式注音排版**：造句練習卡片裡的句子採用直式（由上到下、欄與欄之間由右到左）排版，注音標在每個字的右邊，跟一般注音課本、注音讀物的排法一樣，不是橫式文字上面加注音。句子太長時會自動分成好幾欄（每欄最多 6 個字）。標點符號改用 Unicode 專門給直式文字用的「直式標示符號」（U+FE10～U+FE44 這個區段），而不是原本橫式文字用的標點符號碼位——這樣逗號、句號會由字型直接畫在格子正中央，「「」」引號也會自然靠齊格子的左、右邊，兩個引號上下對起來就有把對話框起來的效果，不用再手動校正位置（真正繁體中文書籍的直排標點就是用這套碼位）。二、三、四聲的聲調符號（ˊˇˋ）跟輕聲的小圓點（˙）也拆出來顯示：二三四聲貼在注音符號右側、大約中間高度、緊貼著自己那組注音（不會因為放大兩倍而跑到隔壁那一行漢字旁邊去）；輕聲則固定貼在整組注音的最上方、置中，跟真正的注音讀本排法一樣是個小記號，而不是跟其他注音符號一樣大小、疊成一整排。聲調符號本身放大成注音符號的兩倍大小（注音符號本身大小不變），方便看清楚是哪一聲。
- **手動調整換行**：直式排版預設每 6 個字自動換一欄，有時候會斷得不自然（例如「我家有一隻」跟「大黑狗」被硬拆成「我家有一隻大」＋「黑狗」）。「紀錄」→「句子紀錄」→「管理句子庫」裡每句話都有「✂️ 調整換行」，可以點兩個字中間的縫隙標記要在哪裡換行，存起來之後複習這句時就會照這個位置分欄，不會再硬套六字規則。修改過句子文字的話，之前設定的換行位置會被清掉（因為字的位置全部變了、原本的位置已經不準），需要重新標一次。
- **可以正常放大縮小畫面**：之前的手機瀏覽器 viewport 設定不小心把「雙指縮放」整個關掉了（`maximum-scale=1.0`），已經拿掉這個限制，現在手機上跟平板一樣可以正常縮放頁面。
- **修正常見破音字注音錯誤**：句子裡的「著」原本不管出現在哪裡都會被自動標成「ㄓㄨˋ」（著作的音），但日常句子裡的「著」絕大多數是當「正在⋯著」的助詞用（笑著、走著、拿著、接著、跟著），應該念輕聲「ㄓㄜ˙」。追查後發現這其實是這套注音函式庫本身的限制，不只「著」，「得」「還」「幾」「長」「覺」「教」「種」「量」「行」「好」「空」「中」「為」這些常見破音字也都有一樣的問題（不管前後文是什麼，永遠只給同一種讀音），例如「因為」「長大」「睡覺」「做得很好」這些超常用詞都曾經被念錯音。已經把這些字都修好：每個字都設定一個大部分情況下正確的預設讀音，只有在少數固定詞（例如「得到」「銀行」「種花」「愛好」）裡才切換成另一個讀音。不排除還有其他更少見的破音字沒被抓到，遇到的話跟之前一樣，把念錯的字跟正確讀音告訴我就能修。
- **句子紀錄可重複練習**：每次生成的 5 句話會標記「衍生自「X」」跟難度存起來，長期保留。到「紀錄」→「句子紀錄」，會依日期列出每天生成過的每一批句子，每一批都有「🔁 練習這批」按鈕，可以隨時把之前任何一天的任何一批句子叫出來重新練習——每次念對都會再拿一次星星，不限一次。
- **複習頁**（底部導覽「複習」分頁）：**打開這一頁本身不會呼叫 AI**。如果句子庫已經有存句子，會先看到一個選複習模式的畫面，而不是直接開始複習。這個選模式的畫面每個地方按下去都有語音：標題、每張卡片的標題和說明文字、「開始隨機複習」、簡單／中等／困難三個難度按鈕、挑字複習的「開始」按鈕、最下面的「產生新句子」，點下去都會先念出來再執行動作：
  - 🎲 **隨機複習**：從整個句子庫（所有日期、所有字詞累積起來的）裡挑最多 10 句到期該複習的句子（類似記憶卡盒 Leitner box 的排程）。
  - 🎯 **挑難度複習**：只挑「簡單」或「中等」或「困難」其中一種難度的句子來複習。
  - 🔤 **挑字複習**：輸入一個字，找出句子庫裡任何地方出現這個字的句子——不限造句時的目標字，例如用「光」造出來的句子一定會被找到，但如果別的字（例如「花」）造出來的句子裡剛好也用到「光」，一樣會被抓出來一起複習。
  
  選好模式、按下開始才會真正進入複習；如果選到的條件沒有句子（例如還沒有任何困難句），會提示換一個條件，不會卡住。複習完畫面上也有「🔁 換個複習模式」可以直接换。這些都是本來就存在「管理句子庫」裡的舊句子，只有按下「產生新句子」才會真的呼叫 AI，自由挑一個已經學過的字或詞另外生成一批（一樣會先進到可編輯清單，確認後才存起來）。句子不理想的話，練習當下可以直接改，這個功能需要額外設定，見下方「設定 AI 造句練習」。
- **管理句子庫**：「紀錄」→「句子紀錄」分頁最上面有「📋 管理句子庫（修改／刪除）」按鈕，可以看到所有存起來的句子，直接修改文字或刪除不要的。難度旁邊也是一個下拉選單，可以直接改成簡單／中等／困難——常見情境是把句子改得更難或更簡單之後，原本的難度標籤已經不準了，改一下就好，不用整句刪掉重造。
- **老師準備區**：「紀錄」→「句子紀錄」分頁、「管理句子庫」按鈕下面有「👩‍🏫 老師準備區」，讓有空的時候可以一次先準備好之後好幾天要教的生字跟句子（例如小朋友一天學一個字，但爸媽有空時一次備好未來五天份），不用等到當天才臨時新增。這裡的操作方式跟「新增」頁幾乎一樣：輸入一個生字或詞彙、選注音、選難度、用 AI 產生或自己寫句子，但存起來之後**不會**馬上算進小朋友的學習紀錄——不會出現在首頁的已學漢字數、「漢字紀錄」「句子紀錄」列表、複習頁的題庫，AI 之後幫其他字造句時也不會把這些準備中的字當成「已經學過」。準備好的內容會列在頁面下方，每個字顯示已經準備了幾句、什麼難度，有兩個按鈕：「🚀 今天開始教這個字」會把這個字跟它的句子正式轉成「今天新增」，這時候才會出現在小朋友能看到的所有地方，跟平常新增的字完全一樣可以拿去複習拿星星；「🗑 刪除整批」則是完全放棄這批準備中的內容，不會留下任何痕跡。如果同一個字已經準備過，再次輸入這個字會直接回到它的準備畫面，方便之後幫它多準備幾種難度的句子；如果輸入的字其實已經正式學過了，會提示不需要再準備。
- **標記不熟的字，加強練習**：練習句子時，句卡下方會列出這句用到的每個字，點一下就能標記「這個字還不熟」（再點一次取消）。之後 AI 生成新句子時，會盡量把標記過的字也自然地組進句子裡（不強求，能自然用上就用，例如標記了「相」「信」，之後就有機會生成「相信」）。這些字集中在「紀錄」→「漢字紀錄」頁最上面的「🧩 需要加強練習的字」區塊管理：可以手動輸入新增，也可以按每個字旁邊的「🪄」直接跳去「造句」頁針對這個字生成新的一批句子；確定已經學會、不用再加強了，按「✕」刪掉就好。
- **漢字紀錄**：「紀錄」→「漢字紀錄」依日期列出每天新增了哪些漢字或詞彙，每個字右上角有「✕」可以刪除（例如不小心新增錯的字）。頁面最上面有「🔍 查詢是否學過」，輸入一個字或詞就能立刻看到「已經學過（哪天新增、注音）」或「還沒學過」，如果這個字有出現在其他已學過的詞裡（例如查「毛」，之前學過「毛毛蟲」），也會列出來；查詢的同時下面的日期列表也會跟著篩選成只顯示符合的字。
- **批次匯入之前學過的字**：在「新增」頁展開「📥 批次匯入之前學過的字」，把一大串之前已經學過的字貼上去，會自動拆成一個一個的字分開儲存（不會當成一個詞），已經學過的字自動略過，也不會觸發造句練習，純粹是把字記錄起來讓 AI 之後造句時知道她已經會這些字。
- **匯出已學漢字**：「紀錄」→「漢字紀錄」頁最上面有「📤 匯出已學漢字」，按「匯出」會把目前學過的所有漢字（自動去除重複、不加任何逗號或分隔符號）整理成一長串文字，自動複製到剪貼簿，也會顯示在下面的文字框讓你手動全選複製。
- **星星轉蛋**：底部導覽「轉蛋」分頁，用累積星星（每次 5 顆）轉蛋收集原創怪獸家族（20 種怪獸 × 爺爺／奶奶／爸爸／媽媽／哥哥／姊姊／弟弟／妹妹／寶寶共 9 種角色，總共 180 種可收集），轉到已經收集過的也算數（畫面上會顯示 xN），收藏牆依怪獸分組、每種怪獸下方是 9 個角色的小格子，顯示還沒轉到的（❔）跟已經轉到的（怪獸圖案）。這是原創角色設計，不是任何現有卡通或遊戲的角色。這一頁每個地方按下去都有語音：標題念「星星轉蛋」、上面說明文字念一次介紹、可用星星／收集進度兩個數字分別點下去會念出目前的數字、禮物盒圖示點下去會念「轉蛋一次，要花五顆星星」、「我的收藏」標題和下面的說明文字也都能點出聲音、每一種怪獸的名字點下去會念出來；下方 9 個角色小格子裡，還沒蒐集到的點下去會念「你還沒蒐集到這個動物」，已經蒐集到的點下去會先念出完整名字（例如「甜心豬爺爺」）再照原本一樣跳轉到那隻怪獸的頁面。星星不夠沒辦法轉蛋時，「轉蛋一次」按鈕不會變成完全沒反應的死按鈕：按下去會有提示音跟語音說「可用星星不夠，要多練習賺星星，才能轉蛋喔」，按鈕本身也還是淡淡地顯示著（只是視覺上比較不顯眼），不會讓小朋友以為按鈕壞掉了。
- **好感度／送禮物**（為 5 歲兒童設計的視覺化版本）：收藏牆裡點一下已經轉到的怪獸，會進到牠的專屬頁面。
  - **友誼成長路**：好感度不再是單純的愛心數字，而是一條 5 站的成長路：🌱初次見面 → ❤️3 👋打招呼 → ❤️5 🤗一起玩 → ❤️8 💌一封信 → ❤️10 💖最好的朋友。還沒到的站顯示灰色鎖頭，畫面下方永遠有一句白話提示（例如「再得到 2 顆心，就可以「一起玩」！」），點一下這句提示還會念出來給小朋友聽；每一站的圖示本身也能點下去，會直接念出那一站的名字（例如點「打招呼」的圖示，就會念「打招呼」），方便還不太認字的小朋友知道每個圖示代表什麼。怪獸下方也固定有一排 10 顆愛心的空格，點一下這排愛心會念出「已經有幾顆愛心」，好感度多少就填滿幾顆，不用理解數字也能一眼看出進度；隨著好感度上升，怪獸旁邊的表情圖示也會從 😐 一路變成 🤩。**每一站解鎖之後不會消失**：畫面上會由新到舊往下堆疊每一個已解鎖的互動（最新解鎖的在最上面），可以往下滑重新看之前的打招呼、一起玩、一封信內容，每一站標題文字本身也可以點下去，念出這一站的名字跟需要幾顆愛心（例如點「打招呼（❤️3）」的標題文字，會念「打招呼，需要三顆愛心」）。點一下怪獸的頭像會先自我介紹（例如「我是甜心豬爺爺。」），解鎖「一起玩」之後點頭像則是自我介紹加上摸摸頭的反應，兩句會接在一起念，不會互相打斷。
  - **送禮卡片**：「⭐️ 可用星星：N」這行標題點下去會念出目前的可用星星數。三個禮物（🍬 小點心／🧸 小玩具／💝 特別禮物）做成大圖案卡片，星星價格和愛心增加量都用重複的 ⭐️／❤️ 圖案直接畫出來（超過 5 個會自動排成兩排），不是只有文字數字。**卡片上的圖片、星星列、愛心列都可以分別點下去，只會用語音講解、不會真的花掉星星**：點圖片說「買小點心」、點星星列說「要花兩顆星星」、點愛心列說「會增加一顆愛心哦」，小朋友可以放心亂點探索。真正要送禮物，要按卡片最下面單獨一顆「送出去！」按鈕，按下去才會播放一整串購買動畫：禮物飛向怪獸 → 怪獸開心蹦跳一下 → 冒出愛心粒子 → 好感度愛心增加 → 怪獸隨機說一句感謝的話（有語音）。可用星星的數字跟愛心格子都會慢慢地一格一格變化（大約 0.6～1.2 秒，特意放慢讓小朋友看得清楚），配合「一飄一沉」的星星／愛心浮動文字，讓小朋友看得出星星真的變少了、愛心真的變多了。星星不夠時不會只是按鈕變灰：星星數字會晃一晃，並顯示「再學幾個字，就有星星送禮物囉」，同時也會有提示音跟語音說「可用星星不夠，要多練習賺星星，才能買東西喔」，不會讓小朋友按了「送出去！」卻完全沒有任何回應、以為是壞掉了。
  - **互動更有參與感**：畫面上永遠只顯示「目前解鎖到的那一關」該做什麼，不會被一長串鎖住的項目洗版。「打招呼」每次按都從好幾句短語音裡隨機挑一句；「一起玩」直接點畫面上的怪獸本人就能摸摸頭，每次都有不同的可愛反應；「一封信」是一個可以點開的信封動畫，打開後看到貼紙和短短的信；「最好的朋友」解鎖的不是一大段文字，而是一張小檔案卡（😍喜歡／😱害怕／🤫小秘密），可以整句用語音播放出來。
  - **角色聲音**：新增了一份角色聲音設定表（`src/lib/voiceProfiles.ts`），依照爺爺／奶奶／爸爸／媽媽／哥哥／姊姊／弟弟／妹妹／寶寶分別設定不同的語速和音調（寶寶語速快、音調最高，用短短的驚嘆詞而不是長句子；爺爺語速慢、音調低）。因為目前用的是瀏覽器內建的 Web Speech API，大部分瀏覽器實際上只提供很少的中文語音（常常只有 1 種），沒辦法做到 9 種角色 9 種真人聲音，所以聲音差異主要靠語速和音調呈現；程式架構上已經把「怎麼發聲」抽成一個可替換的介面（`src/lib/voiceProvider.ts`），未來如果要換成雲端 TTS 或預先錄好的音檔，不需要更動任何呼叫的地方。
  - 因為每隻怪獸的好感度要分開養，180 隻要全部養到最高等級是一個很長期的目標，可以讓小朋友挑幾隻特別喜歡的（例如各種怪獸的「寶寶」跟「妹妹」）花心力養好感度，而不是轉完就丟著。
- **首頁**：顯示已學漢字／詞彙總數、今天新增的字，以及目前有幾句適合複習。星星數分成兩個獨立數字顯示：「累積星星」是從以前到現在總共賺過的星星（不會減少），「可用星星」則是扣掉已經花在轉蛋、送禮物之後現在真正能花的星星——因為累積可能有兩百顆，但如果都花光了，可用星星就會是零，兩個分開顯示才不會讓小朋友以為自己還有很多星星可以花。這一頁上面的標題、每一個數字統計、提示文字、按鈕都點下去有語音；家庭代碼那一行點下去也會念出目前的代碼。
- **全站語音**：底部導覽列（首頁／新增／複習／轉蛋／紀錄）不管在哪一頁，點下去都會先念出那個分頁的名字再切換過去，方便還不太認字的小朋友知道自己按到哪裡；這個導覽列在每一頁共用同一份程式，所以是一次修好、全站都生效。
- **重置測試資料**（給大人用，不在一般選單裡）：測試完想把星星和轉蛋收集歸零、讓小朋友從頭開始存，可以直接在網址列打開 `/#/reset-test-data`（例如 `https://icelog-tu.github.io/Jocelyn-learning-app/#/reset-test-data`）。這個頁面故意沒有放進底部導覽或任何按鈕裡，避免小朋友點到；進去之後還要手動輸入「重置」兩個字才能按確認，多一層保護。會被清空的是累積星星、轉蛋收集到的怪獸、每隻怪獸的好感度；已經學過的漢字／詞彙和存起來的句子不會被刪除或受影響。

## 資料儲存

App 支援兩種模式，由是否設定 Firebase 環境變數決定：

1. **本機模式（預設，不需任何設定）**：資料存在瀏覽器的 localStorage，只在這台裝置、這個瀏覽器上看得到。適合先試用。
2. **雲端同步模式（設定 Firebase 後）**：資料存在 Firestore，只要在不同裝置上輸入同一組「家庭代碼」，就能同步爸媽和女兒裝置上的漢字紀錄。

兩種模式共用同一套 UI／邏輯，兩邊資料各自獨立儲存。**先用本機模式存了資料，之後才設定 Firebase 的話，本機資料不會自動跑到雲端**——「紀錄」頁最上面會顯示目前是本機模式還是雲端同步中；設定好 Firebase 之後重新整理，如果偵測到這台裝置上還留著雲端沒有的舊資料（漢字、句子、需要加強練習的字、轉蛋收集到的怪獸、好感度），會出現「立即備份到雲端」按鈕，按一下就把本機資料原封不動搬到雲端（用同一組 ID，重複按也不會產生重複資料），本機資料本身不會被刪除。

### 家庭代碼安全性說明

雲端同步採用「家庭代碼」而非帳號密碼登入，設計上是為了讓 5 歲小朋友的裝置也能快速使用、不需要輸入帳密。家庭代碼本質上是一組共享密鑰：任何知道這組代碼的人都可以讀寫這個家庭的資料。請不要把代碼公開分享，僅在自己家裡的裝置間使用即可。

## 設定 Firebase 雲端同步（選用）

1. 到 [Firebase Console](https://console.firebase.google.com/) 建立一個新專案（免費方案即可）。
2. 在專案中新增一個 **Web App**（網頁圖示 `</>`），複製產生的 config 設定值。
3. 在左側選單啟用：
   - **Firestore Database**：建立資料庫（正式模式即可，之後會套用下方的安全規則）。
   - **Authentication** → Sign-in method → 啟用 **Anonymous（匿名）** 登入。這是為了讓每個裝置能在不需要輸入帳密的情況下通過 Firestore 安全規則。
4. 到 Firestore 的「規則」分頁，貼上專案根目錄的 [`firestore.rules`](./firestore.rules) 內容並發布。
5. 複製 `.env.example` 為 `.env`，填入步驟 2 拿到的設定值：

   ```bash
   cp .env.example .env
   ```

   ```
   VITE_FIREBASE_API_KEY=...
   VITE_FIREBASE_AUTH_DOMAIN=...
   VITE_FIREBASE_PROJECT_ID=...
   VITE_FIREBASE_STORAGE_BUCKET=...
   VITE_FIREBASE_MESSAGING_SENDER_ID=...
   VITE_FIREBASE_APP_ID=...
   ```

6. 重新啟動 `npm run dev`。開啟 App 時會看到「建立新的家庭空間」，建立後把顯示的代碼記下來，在女兒的裝置上選「加入既有空間」輸入同一組代碼即可同步。

`.env` 內容包含專案設定值，已加入 `.gitignore`，不會被提交到版本控制。

## 設定 AI 造句練習（選用）

這個功能會呼叫 OpenAI 生成句子。**API 金鑰不能直接放在網頁前端**（打開瀏覽器就會被看光，別人可以拿去亂用、花掉你的額度），所以需要另外架一個小小的後端（`worker/` 資料夾，用 [Cloudflare Workers](https://workers.cloudflare.com/)，免費額度很夠用）幫忙保管金鑰、轉發請求。

1. **建立 Cloudflare 帳號**（[dash.cloudflare.com](https://dash.cloudflare.com/sign-up)，免費，不需要信用卡）。

2. **第一次手動部署 Worker**（之後就不用再手動了，見下方「Worker 自動部署」）：

   ```bash
   cd worker
   npm install
   npx wrangler login          # 瀏覽器會跳出來要你登入 Cloudflare
   npx wrangler secret put OPENAI_API_KEY   # 貼上你的 OpenAI API 金鑰
   npm run deploy
   ```

   部署成功後，終端機會印出一個網址，類似：
   ```
   https://hanzi-sentence-worker.<你的帳號>.workers.dev
   ```
   把這個網址記下來。

3. `worker/wrangler.toml` 裡的 `ALLOWED_ORIGIN` 預設是 `https://icelog-tu.github.io`（本專案的 GitHub Pages 網址），Worker 只會接受從這個網址發出的請求，其他來源一律拒絕。如果你的網址不同，記得改這裡再重新部署。

4. 在本機 `.env` 加上這一行（值換成你自己的 Worker 網址）：

   ```
   VITE_SENTENCE_API_URL=https://hanzi-sentence-worker.<你的帳號>.workers.dev
   ```

5. **強烈建議**到 [OpenAI 後台的 Usage limits](https://platform.openai.com/settings/organization/limits) 設定每月花費上限（例如 5 美元）。這是最後一道保險，就算 Worker 網址不小心外流，也不會產生意外的高額帳單。

6. 重新啟動 `npm run dev` 就能在本機測試「AI 造句練習」了。部署版本要怎麼接上這個功能，見下方「部署」章節的 secrets 設定。

### Worker 自動部署

跟前端一樣，`worker/` 資料夾的程式碼有變動並推送到 `main` 或 `claude/hanzi-english-learning-app-bafjgg` 分支時，GitHub Actions 會自動執行 `npm run deploy` 把 Worker 部署到 Cloudflare，不需要再手動回到自己電腦跑指令。

這需要在 repo 的 **Settings → Secrets and variables → Actions** 設定兩個 secret（一次性設定）：

```
CLOUDFLARE_API_TOKEN     # Cloudflare Dashboard → My Profile → API Tokens 建立，權限選「Edit Cloudflare Workers」範本
CLOUDFLARE_ACCOUNT_ID    # Cloudflare Dashboard 首頁可以複製到
```

`OPENAI_API_KEY` 是用 `npx wrangler secret put OPENAI_API_KEY` 另外設定在 Cloudflare 那邊的，不受一般部署影響，重新部署 Worker 不會清掉它，不需要重複設定。

## 部署（GitHub Pages，自動部署）

這個專案設定了 `.github/workflows/deploy.yml`：每次推送到 `main` 或 `claude/hanzi-english-learning-app-bafjgg` 分支，GitHub Actions 就會自動建置並部署到 GitHub Pages，不需要手動操作。

公開網址會是：`https://<GitHub 帳號>.github.io/<repo 名稱>/`（例如 `https://icelog-tu.github.io/Jocelyn-learning-app/`）。

第一次推送後，到 repo 的 **Settings → Pages** 確認 Source 是「GitHub Actions」（通常會自動設定好），並到 **Actions** 分頁看部署是否成功，成功後就能用網址打開。

如果之後有設定 Firebase 或 AI 造句練習（見上方章節）想讓部署版本也能用，需要到 repo 的 **Settings → Secrets and variables → Actions** 新增對應的 secret，值跟本機 `.env` 裡的一樣，設定好之後重新推送一次就會生效：

```
VITE_FIREBASE_API_KEY
VITE_FIREBASE_AUTH_DOMAIN
VITE_FIREBASE_PROJECT_ID
VITE_FIREBASE_STORAGE_BUCKET
VITE_FIREBASE_MESSAGING_SENDER_ID
VITE_FIREBASE_APP_ID
VITE_SENTENCE_API_URL
```

在沒有設定這些 secret 之前，部署版本會自動以本機模式（localStorage）運作、「複習」頁面會顯示 AI 造句還沒設定，其他功能不受影響。

部署後用手機瀏覽器打開網址，可以選擇「加入主畫面」把它加到手機桌面，使用起來就像一個 App。

### 其他部署選項

這是純前端的靜態網頁 App，`npm run build` 後產生的 `dist/` 資料夾其實可以部署到任何靜態網站託管服務（Firebase Hosting、Vercel、Netlify、Cloudflare Pages 等）。如果不想用 GitHub Pages，把 `vite.config.ts` 裡的 `base` 改回 `/`，再依平台說明設定 build command `npm run build`、輸出目錄 `dist` 即可。
